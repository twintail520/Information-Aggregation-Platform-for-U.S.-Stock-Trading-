## 在网页版 Codex 开始

选择此 GitHub 仓库，使用 main 分支创建开发任务，发送：

```text
读取根目录 AGENTS.md 和 docs/product/ 下四份 Markdown，按 03-Codex启动提示词.md 的“首轮启动提示词”执行。先完成 M0（T-001—T-006）和最小纵向切片。检查仓库实际状态，创建 docs/implementation-status.md，完成必要代码、迁移、契约与测试；无密钥使用清晰标记的 mock/fixture 模式。不要只输出开发计划，不要伪造数据或测试结果，不要扩大到 V1/V2。
```

根目录 [AGENTS.md](AGENTS.md) 为 Codex 提供项目读取顺序和工程约束。上传文档不会自行启动另一个 Codex 云任务；需要在网页版选择本仓库并提交上述任务。
